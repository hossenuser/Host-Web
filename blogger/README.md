# Blogger files

- `mh-apps-gallery-theme-with-downloads.xml` - Blogger theme with the Downloads button (menu, Apps section, sidebar). Upload via Blogger > Theme > Backup/Restore. Back up the current theme first.
- `MH-Apps-Gallery-Downloads.html` - standalone download page (logo background). Open in a browser.

Download links point to the `latest-build` release of this repository, which updates on every push to `main`.
